# Planning Poker

Bienvenue sur le projet **Planning Poker**. Ce guide vous aidera à installer et configurer l'environnement de développement localement.

## 🛠 Prérequis

Pour faire fonctionner cette application, vous devez disposer d'un environnement serveur local (Apache, PHP, MySQL).

* **Recommandé :** [WampServer](https://www.wampserver.com/) (Windows)
* Alternative : XAMPP ou MAMP.

## 📥 Installation des fichiers sources

Pour que l'application soit accessible, le code source doit être placé dans le répertoire racine de votre serveur web.

### 1. Localiser le dossier racine
Accédez au dossier d'installation de votre serveur :

* **Sous WampServer :** `C:\wamp64\www\`
* **Sous XAMPP :** `C:\xampp\htdocs\`

### 2. Cloner le dépôt
Ouvrez votre terminal (ou Git Bash) dans ce dossier et exécutez la commande suivante :
